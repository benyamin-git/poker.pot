# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.1] - 2026-10-09

### Fixed

- Backup import no longer shows the native browser file control; importing is a styled tonal button with the picked filename shown underneath.

### Changed

- App icon redesigned: two chip stacks side by side (one larger), no pot mark; refreshed across PWA, desktop and the Android launcher.

## [0.1.0] - 2026-10-08

### Added

- Installable app: the ledger now lives on the device (IndexedDB), no server needed, works offline.
- First-run onboarding wizard: start fresh or import a backup, add players, set limits.
- Backup as one YAML file with replace and merge import modes; merge asks per conflicting session with an apply-to-all option.
- PWA with manifest, icon set, service worker and a non-blocking update banner; installable on iOS via GitHub Pages.
- Android APK via Tauri v2, signed with the release keystore, shipped as a draft GitHub Release.
- App version and last-backup indicator in Settings, plus a gentle nudge when data changed since the last export.

### Changed

- `bun start` now serves the built app as a static preview on `0.0.0.0:7403`; the API server and its data directory are gone.
- `bun run dev` starts Vite only, on `0.0.0.0:7404`.
- Hash-based routing so the app behaves identically on Pages, the preview, and the APK.
- Icons redesigned around a pot mark and generated for every platform.
- Screenshots regenerated by seeding IndexedDB against the static build.

### Removed

- Data-directory setup screen and the host-side YAML session files.
